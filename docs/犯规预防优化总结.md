# 犯规预防优化总结

## 优化目标

**核心问题**：避免误撞黑八和白球洗袋，同时保持进攻性

**设计原则**：
1. **进攻优先**：不削弱进攻能力，这是我们的强项
2. **精准防守**：只在关键位置（黑八、袋口）加强防护
3. **安全球次要**：降低安全球优先级，减少时间消耗
4. **保守兜底**：无法进攻时，轻碰避免犯规

---

## 核心优化

### 1. 黑八力场保护（Tier 1 & 2：几何层）

**位置**：`_is_path_blocked_fast()` 函数

**优化内容**：
```python
# 黑八的安全半径扩大到 3.0 倍球半径（适度保守）
if bid == '8':
    if perp_dist < 3.0 * self.BALL_RADIUS:  # 约 0.086 米
        return True
else:
    # 普通球：2.5 倍球半径
    if perp_dist < 2.5 * self.BALL_RADIUS:
        return True
```

**效果**：
- 在候选生成阶段就过滤掉危险路径
- 不影响正常进攻（只在路径很接近黑八时才阻挡）
- 计算成本：毫秒级（几何计算）

# 1. 白球进袋：-1000（致命失误，直接判负）

### 3. 黑八直线球特殊处理

**位置**：`_generate_smart_ghost_candidates()` 函数

**优化内容**：
```python
if bid == '8':
    # 计算击球角度（切角）
    cos_angle = np.dot(cue_to_ball / np.linalg.norm(cue_to_ball), ball_to_pocket_dir)
    cut_angle = np.degrees(np.arccos(np.clip(cos_angle, -1, 1)))
    
    # 如果是直线球或小角度球（<15度），优先使用低杆/定杆
    if cut_angle < 15:
        spin_variants = [
            (0.0, -0.20),    # 强力低杆（拉杆）- 防止跟进
            (0.0, -0.10),    # 中等低杆
            (0.0, 0.0),      # 定杆（无旋转）
        ]
    else:
        # 大角度球：正常旋转（白球不会跟进）
        spin_variants = [
            (0.0, 0.0),      # 无旋转
            (0.0, -0.15),    # 低杆（拉杆）
            (0.0, 0.10),     # 轻微高杆（适度跟进）
        ]
```

**效果**：
- 根据物理原理（30度规则），直线球使用低杆防止白球跟进
- 大角度球可以正常使用高杆（白球会沿切线方向离开）
- 避免"白球追黑八进袋"的问题

### 4. 快速筛选阶段的犯规过滤

**位置**：`decision()` 函数的 Step 2

**优化内容**：

# 【关键过滤】如果得分<-500，说明有致命犯规

if score < -500:

**效果**：
- 在快速筛选阶段（2次采样）就过滤掉危险候选
- 避免浪费时间在高风险候选上
- 确保始终有安全的备选方案

### 5. 降低安全球优先级

**位置**：`__init__()` 和 `decision()` 函数

**优化内容**：
```python
# 安全球简化（降低优先级，减少时间消耗）
self.safety_max_candidates = 3  # 从5→3，减少候选
self.safety_samples = 1          # 从2→1，只做快速评估

# 只在进攻得分非常低时才考虑安全球
self.safety_trigger_score = 15.0   # 从25→15
self.safety_prefer_margin = 15.0   # 从10→15，必须明显更好才选择
```

**效果**：
- 减少安全球的计算时间（从 5×2=10 次模拟 → 3×1=3 次模拟）
- 只在进攻得分<15时才考虑安全球
- 安全球必须比进攻好15分以上才会选择

## 总结

本次优化聚焦于**犯规预防**，通过以下手段实现：

1. **几何层**：黑八力场（3.0倍半径）
2. **评估层**：致命犯规检测（-1000分）
3. **生成层**：黑八直线球低杆策略
4. **筛选层**：快速过滤危险候选
5. **策略层**：降低安全球优先级

**核心思想**：在保持进攻性的前提下，通过多层防护避免致命犯规。

**预期效果**：
- 误撞黑八：大幅减少（几何层+评估层双重防护）
- 白球洗袋：大幅减少（评估层检测+黑八低杆策略）
- 进攻能力：保持不变（不影响正常候选生成）
- 计算时间：略微减少（安全球优化）
